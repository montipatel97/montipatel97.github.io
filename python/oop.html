Classes & objects

Classes define behavior and objects hold instance state.

Interview focus

Explain class attributes versus instance attributes.

__init__ & self

__init__ initializes an instance; self refers to the instance receiving a method call.

Interview focus

self is conventional, not a reserved keyword.

Inheritance

A child class can reuse and extend parent behavior.

Interview focus

Know super() and method resolution at a high level.

Polymorphism

Different objects can respond to the same interface.

Interview focus

Python often uses duck typing: behavior matters more than explicit inheritance.

Encapsulation & abstraction

Python relies largely on conventions such as _name and name mangling rather than strict private fields.

Interview focus

Explain properties and abstract base classes.

Class/static/dunder methods

classmethod receives cls, staticmethod receives neither implicit instance nor class, and dunder methods integrate objects with Python syntax.

Interview focus

Know __str__, __repr__, __len__ and __eq__.

Quick interview recap

  1. Classes & objects: Explain class attributes versus instance attributes.
  2. __init__ & self: self is conventional, not a reserved keyword.
  3. Inheritance: Know super() and method resolution at a high level.
  4. Polymorphism: Python often uses duck typing: behavior matters more than explicit inheritance.
  5. Encapsulation & abstraction: Explain properties and abstract base classes.
