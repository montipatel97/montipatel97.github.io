Iterators

An iterator produces values with __next__; iter() obtains an iterator.

Interview focus

Iterable and iterator are not identical concepts.

Generators

Generators lazily produce values, often using yield.

Interview focus

Explain memory benefits for large streams.

def nums(n):\n    for i in range(n):\n        yield i

Decorators

A decorator wraps or transforms callable behavior.

Interview focus

Know closures and functools.wraps conceptually.

Context managers

Context managers guarantee setup/cleanup around a block.

Interview focus

Explain why with is safer for files/resources.

with open('x.txt') as f:\n    data = f.read()

Functional tools

map, filter, reduce, zip and enumerate transform or combine iterables.

Interview focus

Know when a comprehension is clearer than map/filter.

collections & functools

Counter, defaultdict, deque, namedtuple and cached/reduced function utilities solve common patterns.

Interview focus

Know deque for efficient queue operations.

Quick interview recap

  1. Iterators: Iterable and iterator are not identical concepts.
  2. Generators: Explain memory benefits for large streams.
  3. Decorators: Know closures and functools.wraps conceptually.
  4. Context managers: Explain why with is safer for files/resources.
  5. Functional tools: Know when a comprehension is clearer than map/filter.
