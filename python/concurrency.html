⚙️ Concurrency

Choose threads, processes or async based on workload and coordination requirements.

Start Learning ↓

Threading

Threads share process memory and are often useful for I/O-bound work.

Interview focus

Mention synchronization and the CPython GIL.

Multiprocessing

Processes have separate memory and can achieve CPU parallelism.

Interview focus

Know serialization and process startup overhead.

async/await

Async code cooperatively switches tasks around await points.

Interview focus

Great for many I/O operations, not automatic CPU parallelism.

asyncio

An event loop schedules coroutines and asynchronous operations.

Interview focus

Do not block the event loop with long CPU-bound work.

Choosing a model

CPU-bound often favors processes; I/O-bound can favor threads or async depending on architecture.

Interview focus

Interviewers care more about the reasoning than memorizing a rule.

Quick interview recap

  1. Threading: Mention synchronization and the CPython GIL.
  2. Multiprocessing: Know serialization and process startup overhead.
  3. async/await: Great for many I/O operations, not automatic CPU parallelism.
  4. asyncio: Do not block the event loop with long CPU-bound work.
  5. Choosing a model: Interviewers care more about the reasoning than memorizing a rule.
