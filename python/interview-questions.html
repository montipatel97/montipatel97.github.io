80 QUESTIONS
PYTHON FUNDAMENTALS🟢 Theory

1. What is the difference between == and is?

== compares values; is compares object identity. Use is None when checking against None.

PYTHON FUNDAMENTALS🟢 Theory

2. Explain mutable vs immutable objects.

Mutable objects can change in place, while immutable objects cannot. Lists and dicts are mutable; strings, integers and tuples are immutable.

PYTHON FUNDAMENTALS🟡 Theory

3. Why are mutable default arguments dangerous?

Default argument objects are created once, so mutations can persist between calls. Use None and create a new object inside the function.

PYTHON FUNDAMENTALS🟡 Theory

4. What are *args and **kwargs?

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dictionary.

DATA STRUCTURES🟢 Theory

5. List vs tuple?

Lists are mutable; tuples are immutable. Tuples can be used where immutability and fixed structure are desirable.

DATA STRUCTURES🟡 Theory

6. How does a dictionary work internally?

A dictionary uses a hash table concept: keys are hashed to locate slots efficiently. Average lookup is O(1), though collisions and resizing exist.

DATA STRUCTURES🟡 Theory

7. Shallow copy vs deep copy?

A shallow copy creates a new outer container but keeps references to nested objects. A deep copy recursively copies nested objects.

DATA STRUCTURES🟢 Theory

8. When would you use a set?

For uniqueness and fast average membership checks, deduplication and set operations such as intersection.

FUNCTIONS & SCOPE🟡 Theory

9. Explain LEGB scope.

Python name lookup generally checks Local, Enclosing, Global and Built-in scopes in that order.

FUNCTIONS & SCOPE🔴 Theory

10. What is a closure?

A closure is a function that retains access to variables from its enclosing scope even after the outer function has returned.

FUNCTIONS & SCOPE🟡 Coding

11. Write a function to count word frequencies.

Use a dictionary or collections.Counter and update counts while iterating through words.

OOP🟢 Theory

12. What is the difference between @classmethod and @staticmethod?

A classmethod receives the class as cls and is useful for alternate constructors or class-level behavior. A staticmethod receives neither self nor cls automatically.

OOP🟡 Theory

13. What is MRO?

Method Resolution Order defines the order Python follows when searching base classes for attributes and methods, especially with multiple inheritance.

OOP🟡 Theory

14. __init__ vs __new__?

__new__ creates and returns an instance; __init__ initializes an instance that has already been created.

ADVANCED PYTHON🟢 Theory

15. Iterable vs iterator?

An iterable can provide an iterator. An iterator also maintains iteration state and provides values via __next__.

ADVANCED PYTHON🟡 Theory

16. Generator vs list comprehension?

A generator is lazy and usually memory-efficient; a list comprehension eagerly builds the full list.

ADVANCED PYTHON🔴 Theory

17. What is a decorator?

A decorator wraps a callable to add or alter behavior without changing the original call site, commonly using closures.

ADVANCED PYTHON🟡 Theory

18. What is a context manager?

A context manager handles setup and cleanup around a block, commonly used through with. It helps ensure resources are released.

ERRORS & FILES🟢 Theory

19. try/except/else/finally difference?

try contains risky code; except handles matching exceptions; else runs when no exception occurs; finally runs for cleanup regardless of outcome.

ERRORS & FILES🟡 Coding

20. How do you process a 20 GB file without loading it into memory?

Stream it incrementally by iterating line by line or in chunks, processing each unit and discarding it before reading more.

INTERNALS & MEMORY🔴 Theory

21. How does memory management work in CPython?

CPython primarily uses reference counting and also has cyclic garbage collection for reference cycles.

INTERNALS & MEMORY🔴 Theory

22. What is the GIL?

In standard CPython builds, the GIL allows only one thread to execute Python bytecode at a time. Threads can still help I/O-bound work; processes are often better for CPU-bound parallelism.

CONCURRENCY🟡 Theory

23. Threading vs multiprocessing vs asyncio?

Threads share memory and suit many I/O workloads; processes use separate memory and enable CPU parallelism; asyncio uses cooperative concurrency around await points for many I/O tasks.

CONCURRENCY🔴 Theory

24. Why should you not call blocking code directly inside an async coroutine?

It can block the event loop and prevent other tasks from progressing. Use an async library or offload blocking work appropriately.

DATA ENGINEERING🟡 Theory

25. How would you make an API ingestion script production-ready?

Use timeouts, retries with backoff, pagination, validation, structured logging, idempotency where needed, checkpoints and secure configuration.

DATA ENGINEERING🟡 Theory

26. How do you handle malformed records in a pipeline?

Define validation rules, capture rejected records with reasons, log metrics, and choose fail-fast versus quarantine behavior based on data contracts.

CODING🟢 Coding

27. Find duplicates in a list efficiently.

Track seen values in a set and collect values encountered again; complexity is typically O(n) time and O(n) extra space.

CODING🟡 Coding

28. Longest substring without repeating characters?

Use a sliding window plus a dictionary/set to track characters, moving the left boundary when a duplicate violates the window.

CODING🟡 Coding

29. Find the second largest distinct number.

Track the largest and second-largest distinct values in one pass, carefully handling duplicates and missing second values.

PYTHON FUNDAMENTALS🟢 Theory

30. What is the difference between pass, continue and break?

pass does nothing, continue skips to the next loop iteration, and break exits the nearest loop.

PYTHON FUNDAMENTALS🟡 Theory

31. What is truthiness in Python?

Objects can be evaluated as true or false in boolean contexts. Empty containers, zero and None are falsey; most other objects are truthy.

PYTHON FUNDAMENTALS🟡 Theory

32. What is duck typing?

Python commonly focuses on whether an object supports the required behavior rather than its explicit class hierarchy.

DATA STRUCTURES🟢 Theory

33. What is the average complexity of list append and dictionary lookup?

Appending to the end of a Python list is amortized O(1); dictionary lookup is average O(1), subject to hashing and collisions.

DATA STRUCTURES🟡 Theory

34. Why must dictionary keys be hashable?

A dictionary uses hashes to locate keys consistently. Mutable objects whose hash could change cannot safely act as normal dictionary keys.

DATA STRUCTURES🟡 Coding

35. How do you merge two dictionaries?

Use {**a, **b} or a | b in modern Python. If keys overlap, the right-hand dictionary wins.

DATA STRUCTURES🟡 Coding

36. How do you flatten a nested list?

Use nested iteration or a comprehension for known depth. For arbitrary nesting, recursion or an explicit stack is required.

DATA STRUCTURES🟡 Theory

37. Counter vs defaultdict?

Counter is specialized for counting hashable items; defaultdict automatically creates a default value for missing keys.

FUNCTIONS & SCOPE🟡 Theory

38. Are Python arguments passed by value or reference?

Python uses object references passed to functions. A function receives a reference to the same object; mutation and rebinding therefore behave differently.

FUNCTIONS & SCOPE🟡 Theory

39. What does nonlocal do?

nonlocal allows an inner function to rebind a variable from the nearest enclosing function scope.

FUNCTIONS & SCOPE🔴 Theory

40. What is late binding in closures?

Closures capture names, so loop-created closures can all observe a later value unless it is captured deliberately, for example with a default argument.

FUNCTIONS & SCOPE🟢 Coding

41. Reverse a string in Python.

Use slicing s[::-1] for a concise solution, or reversed(s) when an iterator is useful.

OOP🟡 Theory

42. What is __slots__?

__slots__ can restrict instance attribute storage and reduce per-instance memory in suitable designs, with trade-offs in flexibility.

OOP🟡 Theory

43. What is a property in Python?

property lets attribute-style access call managed getter/setter/deleter logic, useful for validation or computed attributes.

OOP🔴 Theory

44. Explain multiple inheritance and the diamond problem.

A class can inherit from multiple bases. Python resolves method lookup using C3 linearization, exposed through the MRO.

OOP🟡 Theory

45. __str__ vs __repr__?

__str__ is for a readable user-facing representation; __repr__ aims for an unambiguous developer representation.

ADVANCED PYTHON🟡 Theory

46. What happens when a generator is exhausted?

Further next() calls raise StopIteration. Iterating over it again does not restart the original generator.

ADVANCED PYTHON🟡 Theory

47. yield vs return?

return finishes a function and optionally provides one final value; yield suspends a generator and produces a value while preserving state.

ADVANCED PYTHON🔴 Theory

48. Why use functools.wraps in decorators?

It preserves metadata such as the wrapped function's name and documentation, improving debugging and introspection.

ADVANCED PYTHON🟡 Coding

49. How do you implement a simple decorator?

Create a function that accepts a function and returns a wrapper; the wrapper can perform work before and after calling the original function.

ADVANCED PYTHON🟡 Theory

50. What does zip do?

zip lazily pairs items from iterables and stops at the shortest input unless a strict strategy is requested.

ERRORS & FILES🟡 Theory

51. Why is bare except usually discouraged?

It can hide programming errors and system-level exceptions. Catch expected exception classes and handle them deliberately.

ERRORS & FILES🟡 Theory

52. How do you safely write a file in production?

Write with explicit encoding and error handling; for critical outputs consider writing a temporary file and atomically replacing the destination.

ERRORS & FILES🟢 Theory

53. json.load vs json.loads?

json.load reads JSON from a file-like object; json.loads parses JSON from a string or bytes.

INTERNALS & MEMORY🟡 Theory

54. Why does changing a list inside a function affect the caller?

Both caller and function can reference the same mutable list object, so in-place mutation is visible through both references.

INTERNALS & MEMORY🔴 Theory

55. What can cause memory leaks in Python?

Long-lived references, global caches, retained containers, unbounded queues and cycles involving objects with complex lifecycle behavior can retain memory unexpectedly.

INTERNALS & MEMORY🟡 Theory

56. What is interning?

Some implementations may reuse certain immutable objects, but identity reuse is an implementation detail and should not be relied on for general logic.

CONCURRENCY🟡 Theory

57. What is a race condition?

A race condition occurs when correctness depends on timing or interleaving of concurrent operations without sufficient coordination.

CONCURRENCY🟡 Theory

58. What is a deadlock?

Concurrent tasks wait indefinitely for resources held by one another. Consistent lock ordering and short critical sections help reduce risk.

CONCURRENCY🔴 Theory

59. What is an event loop?

An event loop schedules and advances asynchronous tasks, switching when tasks await non-blocking operations.

CONCURRENCY🟡 Theory

60. When should you use a thread pool?

For many blocking or I/O-oriented tasks where shared process memory is convenient and managing individual threads directly is unnecessary.

DATA ENGINEERING🟡 Theory

61. What is idempotency in a data pipeline?

Repeating an operation produces the same final result, which makes retries safer.

DATA ENGINEERING🟡 Theory

62. How would you process paginated API data reliably?

Persist progress/checkpoints, use timeouts and bounded retries, handle rate limits, validate responses and make downstream writes idempotent where possible.

DATA ENGINEERING🟡 Theory

63. Why use generators in ETL code?

They support lazy processing and can reduce memory use when handling large streams.

DATA ENGINEERING🟡 Theory

64. How should secrets be handled?

Keep secrets out of source code and logs; inject them through environment configuration or a dedicated secret-management system.

DATA ENGINEERING🔴 Theory

65. How do you design retry logic?

Retry only transient failures, use bounded exponential backoff with jitter where appropriate, respect idempotency and surface persistent failures clearly.

CODING🟢 Coding

66. Check whether a string is a palindrome.

Compare the string with its reverse, or use two pointers when normalization or memory constraints matter.

CODING🟢 Coding

67. Find the first non-repeating character.

Count frequencies, then scan in original order for the first character whose count is one.

CODING🟡 Coding

68. Two Sum: find two values with a target sum.

Scan once with a hash map of previously seen values and check whether target - current already exists.

CODING🟡 Coding

69. Validate balanced parentheses.

Use a stack: push opening brackets and match each closing bracket against the latest opening bracket.

CODING🟡 Coding

70. Merge two sorted arrays.

Use two pointers and repeatedly take the smaller current value; complexity is O(n+m).

CODING🔴 Coding

71. How do you find a cycle in a linked list?

Use Floyd's tortoise-and-hare algorithm with slow and fast pointers.

CODING🟡 Coding

72. Top K frequent elements?

Count frequencies and use an appropriate heap, bucket strategy or sorting depending on constraints.

CODING🔴 Coding

73. How do you reason about time and space complexity?

Count dominant operations as input grows and separately account for auxiliary storage, recursion depth and data-structure overhead.

PYTHON INTERVIEW🟡 Theory

74. What is the difference between sorted() and list.sort()?

sorted() returns a new sorted list from an iterable; list.sort() sorts a list in place and returns None.

PYTHON INTERVIEW🟡 Theory

75. map/filter vs comprehensions?

Both can express transformations; comprehensions are often clearer for simple Python expressions, while map/filter can be useful with existing callables and lazy iterators.

PYTHON INTERVIEW🔴 Theory

76. What happens when importing a module?

Python locates the module, executes its top-level code to initialize it, and generally caches the resulting module object for later imports.

PYTHON INTERVIEW🟡 Theory

77. What is __name__ == '__main__' used for?

It distinguishes direct script execution from importing the file as a module, so executable entry-point code can be guarded.

PYTHON INTERVIEW🔴 Theory

78. What is monkey patching and why is it risky?

It changes attributes at runtime. It can be useful in controlled tests but can make production behavior implicit and difficult to reason about.

PYTHON INTERVIEW🟡 Coding

79. How would you remove duplicates while preserving order?

Use a set to track seen values and append each value only the first time it appears.

PYTHON INTERVIEW🔴 Coding

80. How would you find the largest contiguous sum?

Use Kadane's algorithm, tracking the best sum ending at the current position and the best overall sum.
