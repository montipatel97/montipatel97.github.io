29 QUESTIONS
PYTHON FUNDAMENTALS🟢 Theory

1. What is the difference between == and is?

== compares values; is compares object identity. Use is None when checking against None.

PYTHON FUNDAMENTALS🟢 Theory

2. Explain mutable vs immutable objects.

Mutable objects can change in place, while immutable objects cannot. Lists and dicts are mutable; strings, integers and tuples are immutable.

PYTHON FUNDAMENTALS🟡 Theory

3. Why are mutable default arguments dangerous?

Default argument objects are created once, so mutations can persist between calls. Use None and create a new object inside the function.

PYTHON FUNDAMENTALS🟡 Theory

4. What are *args and **kwargs?

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dictionary.

DATA STRUCTURES🟢 Theory

5. List vs tuple?

Lists are mutable; tuples are immutable. Tuples can be used where immutability and fixed structure are desirable.

DATA STRUCTURES🟡 Theory

6. How does a dictionary work internally?

A dictionary uses a hash table concept: keys are hashed to locate slots efficiently. Average lookup is O(1), though collisions and resizing exist.

DATA STRUCTURES🟡 Theory

7. Shallow copy vs deep copy?

A shallow copy creates a new outer container but keeps references to nested objects. A deep copy recursively copies nested objects.

DATA STRUCTURES🟢 Theory

8. When would you use a set?

For uniqueness and fast average membership checks, deduplication and set operations such as intersection.

FUNCTIONS & SCOPE🟡 Theory

9. Explain LEGB scope.

Python name lookup generally checks Local, Enclosing, Global and Built-in scopes in that order.

FUNCTIONS & SCOPE🔴 Theory

10. What is a closure?

A closure is a function that retains access to variables from its enclosing scope even after the outer function has returned.

FUNCTIONS & SCOPE🟡 Coding

11. Write a function to count word frequencies.

Use a dictionary or collections.Counter and update counts while iterating through words.

OOP🟢 Theory

12. What is the difference between @classmethod and @staticmethod?

A classmethod receives the class as cls and is useful for alternate constructors or class-level behavior. A staticmethod receives neither self nor cls automatically.

OOP🟡 Theory

13. What is MRO?

Method Resolution Order defines the order Python follows when searching base classes for attributes and methods, especially with multiple inheritance.

OOP🟡 Theory

14. __init__ vs __new__?

__new__ creates and returns an instance; __init__ initializes an instance that has already been created.

ADVANCED PYTHON🟢 Theory

15. Iterable vs iterator?

An iterable can provide an iterator. An iterator also maintains iteration state and provides values via __next__.

ADVANCED PYTHON🟡 Theory

16. Generator vs list comprehension?

A generator is lazy and usually memory-efficient; a list comprehension eagerly builds the full list.

ADVANCED PYTHON🔴 Theory

17. What is a decorator?

A decorator wraps a callable to add or alter behavior without changing the original call site, commonly using closures.

ADVANCED PYTHON🟡 Theory

18. What is a context manager?

A context manager handles setup and cleanup around a block, commonly used through with. It helps ensure resources are released.

ERRORS & FILES🟢 Theory

19. try/except/else/finally difference?

try contains risky code; except handles matching exceptions; else runs when no exception occurs; finally runs for cleanup regardless of outcome.

ERRORS & FILES🟡 Coding

20. How do you process a 20 GB file without loading it into memory?

Stream it incrementally by iterating line by line or in chunks, processing each unit and discarding it before reading more.

INTERNALS & MEMORY🔴 Theory

21. How does memory management work in CPython?

CPython primarily uses reference counting and also has cyclic garbage collection for reference cycles.

INTERNALS & MEMORY🔴 Theory

22. What is the GIL?

In standard CPython builds, the GIL allows only one thread to execute Python bytecode at a time. Threads can still help I/O-bound work; processes are often better for CPU-bound parallelism.

CONCURRENCY🟡 Theory

23. Threading vs multiprocessing vs asyncio?

Threads share memory and suit many I/O workloads; processes use separate memory and enable CPU parallelism; asyncio uses cooperative concurrency around await points for many I/O tasks.

CONCURRENCY🔴 Theory

24. Why should you not call blocking code directly inside an async coroutine?

It can block the event loop and prevent other tasks from progressing. Use an async library or offload blocking work appropriately.

DATA ENGINEERING🟡 Theory

25. How would you make an API ingestion script production-ready?

Use timeouts, retries with backoff, pagination, validation, structured logging, idempotency where needed, checkpoints and secure configuration.

DATA ENGINEERING🟡 Theory

26. How do you handle malformed records in a pipeline?

Define validation rules, capture rejected records with reasons, log metrics, and choose fail-fast versus quarantine behavior based on data contracts.

CODING🟢 Coding

27. Find duplicates in a list efficiently.

Track seen values in a set and collect values encountered again; complexity is typically O(n) time and O(n) extra space.

CODING🟡 Coding

28. Longest substring without repeating characters?

Use a sliding window plus a dictionary/set to track characters, moving the left boundary when a duplicate violates the window.

CODING🟡 Coding

29. Find the second largest distinct number.

Track the largest and second-largest distinct values in one pass, carefully handling duplicates and missing second values.
