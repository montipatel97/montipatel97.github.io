Variables & objects

Python variables are names bound to objects; type belongs to the object, not the variable.

Interview focus

Explain dynamic typing without saying Python has no types.

x = 10\nx = 'hello'

Built-in types

Understand int, float, bool, str and None, plus container types.

Interview focus

Know truthiness and common type-conversion questions.

bool([])  # False\nint('42') # 42

Operators

Arithmetic, comparison, logical, membership and identity operators have different purposes.

Interview focus

Explain == versus is early and correctly.

Conditions

if, elif and else branch based on truthiness.

Interview focus

Know short-circuit behavior of and/or.

Loops

for iterates over an iterable; while repeats while a condition is true.

Interview focus

Know break, continue and loop else.

for x in range(3):\n    print(x)

Quick interview recap

  1. Variables & objects: Explain dynamic typing without saying Python has no types.
  2. Built-in types: Know truthiness and common type-conversion questions.
  3. Operators: Explain == versus is early and correctly.
  4. Conditions: Know short-circuit behavior of and/or.
  5. Loops: Know break, continue and loop else.
