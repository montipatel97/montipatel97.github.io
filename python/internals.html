References

Variables hold references to objects; assignment usually does not copy an object.

Interview focus

Use id() to discuss identity, not as business logic.

Mutable vs immutable

Mutation changes an existing object; immutable operations create a new value/object.

Interview focus

Know the implications for function arguments and dictionary keys.

is vs ==

== compares value equality; is compares object identity.

Interview focus

Use is None for None checks.

Copying

copy.copy is shallow and copy.deepcopy recursively copies nested structures.

Interview focus

Know shared nested references.

Garbage collection

CPython uses reference counting plus a cyclic garbage collector.

Interview focus

Avoid assuming every Python implementation behaves exactly like CPython.

GIL

In CPython, the GIL limits simultaneous execution of Python bytecode by multiple threads.

Interview focus

Threads can still help I/O-bound workloads; processes help CPU-bound parallelism.

Quick interview recap

  1. References: Use id() to discuss identity, not as business logic.
  2. Mutable vs immutable: Know the implications for function arguments and dictionary keys.
  3. is vs ==: Use is None for None checks.
  4. Copying: Know shared nested references.
  5. Garbage collection: Avoid assuming every Python implementation behaves exactly like CPython.
