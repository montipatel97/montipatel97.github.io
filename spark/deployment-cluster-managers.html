DEPLOYMENT

Deployment Mental Model

spark-submit→Cluster Manager→Driver→Executors→Tasks

Cluster managers allocate resources; Spark uses acquired executors to execute tasks for an application.

Interview focus

Spark itself schedules tasks, while the cluster manager allocates the underlying resources.

CLUSTERS

Cluster Managers

StandaloneSimple Spark-native cluster manager.
YARNCommon Hadoop ecosystem resource manager.
KubernetesContainer orchestration and pod-based deployment.

Interview focus

Choose based on infrastructure and operational ecosystem, not because one is universally faster.

DEPLOY MODE

Client vs Cluster Mode

ClientDriver runs with the submitting process.
ClusterDriver runs inside cluster-managed infrastructure.

Driver network accessibility and lifecycle are important considerations.

Interview focus

Cluster mode is generally more robust for production submission because the submitter can disconnect after launch, depending on manager behavior.

SUBMISSION

spark-submit

Applications are submitted with spark-submit, specifying application resources, master/deploy mode and relevant configuration.

spark-submit --master yarn --deploy-mode cluster app.py

Interview focus

Know the difference between where resources are requested and where the driver runs.

STANDALONE

Standalone

Standalone is Spark's built-in cluster manager. It is straightforward to set up and useful for dedicated Spark clusters.

Interview focus

Know master, worker and executor roles.

YARN

Running on YARN

YARN manages cluster resources. In cluster mode the Spark driver runs inside the cluster-managed application environment; in client mode it remains in the submitting client process.

Interview focus

For YARN interviews, clearly distinguish ApplicationMaster/resource allocation from the Spark driver location.

KUBERNETES

Running on Kubernetes

Spark applications can run with driver and executor pods managed through Kubernetes APIs, images and namespaces.

Interview focus

Know pods, container images, RBAC/permissions and resource requests at a conceptual level.

Q&A

Deployment Interview Vault

Cluster manager?
Allocates resources for Spark applications.
Driver?
Coordinates the Spark application and schedules tasks.
Executor?
Runs tasks and can retain application data.
Client vs cluster?
Primarily where the driver process runs.

Interview focus

Always separate resource allocation from Spark task scheduling.
