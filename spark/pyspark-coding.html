Window Functions

from pyspark.sql.window import Window
w = Window.partitionBy("department").orderBy("salary")

df.withColumn("rank", F.dense_rank().over(w)) \
  .withColumn("previous_salary", F.lag("salary").over(w))

df.withColumn("moving_avg", F.avg("salary").over(rolling))

CODING PRACTICE

50 PySpark Interview Problems

Easy → Hard

Try each problem yourself first. Then open the answer to compare the approach and key PySpark pattern.

1Find duplicate records+
Approach

Group by business keys and filter counts greater than one.

df.groupBy('email').count().filter('count > 1')
2Remove duplicates keeping latest+
Approach

Use row_number ordered by the timestamp descending.

w = Window.partitionBy('id').orderBy(F.col('updated_at').desc())
3Second highest salary per department+
Approach

Use dense_rank over department ordered by salary descending.

F.dense_rank().over(w)
4Top 3 salaries per department+
Approach

Rank within each department and filter rank <= 3.

Window.partitionBy('dept').orderBy(F.col('salary').desc())
5Running total+
Approach

Use sum over an ordered window from unbounded preceding to current row.

F.sum('amount').over(w.rowsBetween(Window.unboundedPreceding, 0))
63-row moving average+
Approach

Use rowsBetween(-2, 0) with avg.

F.avg('value').over(w.rowsBetween(-2,0))
7Difference from previous row+
Approach

Use lag and subtract.

F.col('value') - F.lag('value').over(w)
8Latest transaction per customer+
Approach

row_number by customer and descending timestamp.

F.row_number().over(w)
9Percentage of total+
Approach

Divide value by a window sum over the required scope.

F.col('amount') / F.sum('amount').over(Window.partitionBy())
10Conditional aggregation+
Approach

Use sum with when conditions.

F.sum(F.when(F.col('status')=='paid',1).otherwise(0))
11Customers with no orders+
Approach

Use left anti join.

customers.join(orders,'customer_id','left_anti')
12Find changed records+
Approach

Join old/new datasets and compare tracked columns.

old.alias('o').join(new.alias('n'),'id')
13Flatten array column+
Approach

Use explode.

df.select('*',F.explode('items').alias('item'))
14Flatten nested struct+
Approach

Select struct fields explicitly.

df.select('user.*')
15Parse JSON+
Approach

Use from_json with an explicit schema.

F.from_json('payload', schema)
16Fill nulls by type+
Approach

Use fillna with a dictionary or separate column logic.

df.fillna({'city':'unknown','amount':0})
17Detect gaps in dates+
Approach

Use lag to compare current date with prior date.

F.datediff('date',F.lag('date').over(w))
18Consecutive-day streaks+
Approach

Combine lag/date differences with cumulative grouping.

Window + lag + cumulative sum
19Sessionization+
Approach

Create a new session flag when timestamp gap exceeds threshold, then cumulative-sum the flag.

lag(timestamp) + when(gap > threshold,1)
20Pivot categories+
Approach

Group and pivot on category.

df.groupBy('id').pivot('category').agg(F.sum('amount'))
21Unpivot columns+
Approach

Use stack/SQL expression or DataFrame unpivot where appropriate.

df.unpivot(...)
22Broadcast dimension+
Approach

Broadcast only a genuinely small side.

join(broadcast(dim), 'key')
23Handle skewed join+
Approach

Measure hot keys, then consider AQE, broadcast or targeted salting.

AQE / targeted salting
24SCD Type 2 concept+
Approach

Expire changed current rows and insert a new version with effective dates.

compare hashes/columns + current flag
25Data quality checks+
Approach

Add explicit null, uniqueness, range and schema validations before publishing.

filter invalid rows + metrics
26Incremental load+
Approach

Read a bounded change range/watermark and make writes idempotent.

filter by watermark + merge strategy
27Deduplicate streaming-like events+
Approach

Use business keys and timestamp rules; in streaming include state/watermark semantics.

dropDuplicates / stateful dedup
28Multi-column join safely+
Approach

Use aliases and explicit conditions to avoid ambiguity.

left.alias('l').join(right.alias('r'), condition)
29Array aggregation+
Approach

Collect values only when resulting arrays remain bounded.

F.collect_list('value')
30Map/struct creation+
Approach

Build complex columns with map/struct functions.

F.struct('id','name')
31UDF decision+
Approach

Built-in function first, then SQL expression; only then consider UDF/Pandas UDF.

Prefer JVM/native execution path
32Partitioned output+
Approach

Partition by low-to-moderate cardinality columns used for downstream filtering.

write.partitionBy('event_date')
33Union with schema order changes+
Approach

Use unionByName when appropriate.

df1.unionByName(df2)
34Multiple withColumn issue+
Approach

For many derived columns, prefer clear transformations and avoid huge repeated plans.

select expressions / withColumns
35Avoid collect in production+
Approach

Keep data distributed; use limits/samples/aggregations for inspection.

df.limit(100).show()
36Debug slow transformation+
Approach

Start from UI stage/task metrics and explain plan.

UI → task skew → explain
37Count nulls per column+
Approach

Use conditional sums for each column.

sum(when(col.isNull(),1))
38Remove whitespace and normalize text+
Approach

Use trim/lower/regexp_replace.

F.lower(F.trim('name'))
39Extract year/month/day+
Approach

Use date functions rather than Python row UDFs.

F.year('date')
40First and last record+
Approach

Use row_number with ascending/descending order windows.

row_number over ordered window
41Rank vs dense_rank+
Approach

rank leaves gaps after ties; dense_rank does not.

rank()/dense_rank()
42Running percentage+
Approach

Combine cumulative sum and total window sum.

cum_sum / total_sum
43Join and select without duplicates+
Approach

Select explicit columns after aliases.

select('l.*','r.dimension')
44Filter before join+
Approach

Push selective filters before expensive joins when semantics allow.

df.filter(...).join(...)
45Repartition before write+
Approach

Use only when output parallelism/layout needs redistribution.

repartition(n, key)
46Coalesce before write+
Approach

Often useful to reduce output partitions with less movement.

coalesce(n)
47Explode multiple arrays+
Approach

Understand positional semantics; use arrays_zip when elements must stay aligned.

F.explode(F.arrays_zip(...))
48Nested schema evolution+
Approach

Select explicit fields and manage missing/new fields deliberately.

explicit schema + defaults
49Mini ETL challenge+
Approach

Read → clean → dedupe → enrich → aggregate → partitioned write.

end-to-end DataFrame pipeline

Approach

Explain correctness first, then performance and operational considerations.
