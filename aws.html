Object storage, buckets, objects, prefixes, partitions, lifecycle and data-lake design.

For data engineering, think in layers such as raw/bronze, cleaned/silver and curated/gold. Good key/prefix layout supports scalable downstream processing.

SERVERLESS SQL

Amazon Athena

Query data directly in S3 using SQL, metadata and efficient file/partition design.

Use partition pruning, columnar formats and selecting only required columns to reduce work and improve query efficiency.

Which service should process the data?

Start with workload requirements: serverless ETL, interactive SQL, warehouse analytics or flexible distributed processing.

Which service orchestrates the pipeline?

Use explicit workflow orchestration when dependencies, retries, branching and long-running steps need coordination.

What is the most common architecture question?
