01 • SQL FUNDAMENTALS

SELECT

SELECT is used to choose which columns or expressions you want to retrieve from a table.

Syntax

SELECT column1, column2
FROM table_name;

Example

SELECT employee_name, salary
FROM employees;

💡 Interview tip: SELECT * returns every column, but explicitly selecting required columns is usually clearer and more efficient.

02 • FILTERING DATA

WHERE

WHERE filters rows before the final result is returned.

Syntax

SELECT column1, column2
FROM table_name
WHERE condition;

Example

SELECT employee_name, salary
FROM employees
WHERE salary > 50000;

You can combine conditions with AND, OR and NOT.

SELECT *
FROM employees
WHERE department = 'Engineering'
  AND salary >= 70000;

💡 Remember: WHERE filters rows, while HAVING filters groups after aggregation.

03 • UNIQUE VALUES

DISTINCT

DISTINCT removes duplicate rows from the selected result.

Example

SELECT DISTINCT department
FROM employees;

For multiple columns, uniqueness is evaluated using the combination of all selected columns.

SELECT DISTINCT department, job_title
FROM employees;

💡 Interview tip: Be ready to explain the difference between DISTINCT and using GROUP BY to obtain unique combinations.

04 • SORTING RESULTS

ORDER BY

ORDER BY sorts the final result set. Use ASC for ascending order and DESC for descending order.

Example

SELECT employee_name, salary
FROM employees
ORDER BY salary DESC;

You can sort by multiple columns.

SELECT employee_name, department, salary
FROM employees
ORDER BY department ASC, salary DESC;

💡 Common mistake: SQL does not guarantee row order unless you explicitly use ORDER BY.

05 • RESTRICTING RESULTS

LIMIT

LIMIT restricts the number of rows returned in SQL dialects that support it, such as PostgreSQL and MySQL.

Example

SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 5;

This returns the top 5 rows after sorting.

💡 Dialect note: SQL Server commonly uses TOP, while other databases may use FETCH FIRST.

06 • RENAMING OUTPUT

Aliases

An alias gives a temporary name to a column or table, making queries easier to read.

Column alias

SELECT employee_name AS name,
       salary AS annual_salary
FROM employees;

Table alias

SELECT e.employee_name,
       e.salary
FROM employees AS e;

💡 Interview tip: Table aliases become especially useful in joins and self-joins.
