Data types & NULL

Choose types that fit domain, range and precision. NULL means missing or unknown and needs deliberate handling.

Interview focus

Explain CHAR vs VARCHAR, numeric precision and why NULL comparisons require IS NULL.

CREATE TABLE users (id BIGINT PRIMARY KEY, email VARCHAR(255) NOT NULL UNIQUE);

Command families

DDL defines structure, DML changes rows, DCL controls permissions and TCL controls transactions.

Interview focus

DDL vs DML vs DCL vs TCL is a classic fundamentals question.

Keys

Primary, candidate, alternate, super, foreign and composite keys express identity and relationships.

Interview focus

Explain why a primary key identifies a row and why a composite key may be appropriate.

Constraints

NOT NULL, UNIQUE, CHECK, PRIMARY KEY and FOREIGN KEY enforce rules close to the data.

Interview focus

Why enforce integrity in the database instead of trusting application code?

ER modeling

Model entities and one-to-one, one-to-many and many-to-many relationships before creating tables.

Interview focus

Translate a many-to-many relationship into a junction table and define its key.

  4. Constraints: Why enforce integrity in the database instead of trusting application code?
  5. ER modeling: Translate a many-to-many relationship into a junction table and define its key.
