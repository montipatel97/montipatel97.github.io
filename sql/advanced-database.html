Views

Views expose a saved query as a virtual table-like interface.

Interview focus

Views simplify abstraction but are not automatically a performance optimization.

Materialized views

Materialized views store query results and require refresh strategies.

Interview focus

Use when expensive reads benefit from precomputation and freshness trade-offs are acceptable.

Stored procedures & functions

Reusable server-side logic can centralize database operations.

Interview focus

Discuss portability, testing and version-control trade-offs.

Triggers

Triggers execute automatically in response to database events.

Interview focus

Useful for selected integrity or audit workflows but can hide side effects.

Recursive CTEs

Recursive CTEs traverse hierarchies such as org charts and trees.

Interview focus

Explain anchor member, recursive member and termination.

Security

Roles and GRANT/REVOKE control access; parameterized queries help prevent injection.

Interview focus

Never concatenate untrusted input into executable SQL.

Partitioning & scaling

Partitioning, replication and other choices address different bottlenecks.

Interview focus

Be clear whether the goal is pruning, availability, read scaling or write scaling.

Quick interview recap

  1. Views: Views simplify abstraction but are not automatically a performance optimization.
  2. Materialized views: Use when expensive reads benefit from precomputation and freshness trade-offs are acceptable.
  3. Stored procedures & functions: Discuss portability, testing and version-control trade-offs.
  4. Triggers: Useful for selected integrity or audit workflows but can hide side effects.
  5. Recursive CTEs: Explain anchor member, recursive member and termination.
