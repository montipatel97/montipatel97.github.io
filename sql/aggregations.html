01 • SUMMARIZING DATA

COUNT, SUM, AVG, MIN, MAX

Aggregate functions calculate one result over multiple rows.

Syntax / pattern

SELECT COUNT(*), SUM(amount), AVG(amount)
FROM orders;

Example

SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;

🎯 Interview question: COUNT(*) vs COUNT(column)?

Answer: COUNT(*) counts rows; COUNT(column) counts only non-NULL values in that column.

🎯 Interview question: Does AVG ignore NULL?

Answer: Yes. Standard aggregate functions generally ignore NULL values, except COUNT(*) which counts rows.

02 • CREATE GROUPS

GROUP BY

GROUP BY creates one output group for each unique combination of the grouped columns.

Syntax / pattern

SELECT group_column, AGG(value)
FROM table
GROUP BY group_column;

Example

SELECT department, COUNT(*) AS employees
FROM employees
GROUP BY department;

🎯 Interview question: Why can't you SELECT an ungrouped non-aggregated column?

Answer: Because SQL would not know which row's value to return for that group.

🎯 Interview question: Can you group by multiple columns?

Answer: Yes; the combination of columns defines each group.

03 • FILTERING GROUPS

HAVING

WHERE filters rows before grouping; HAVING filters aggregated groups after GROUP BY.

Syntax / pattern

SELECT ... FROM table
WHERE row_condition
GROUP BY col
HAVING aggregate_condition;

Example

SELECT department, AVG(salary) avg_salary
FROM employees
WHERE active = true
GROUP BY department
HAVING AVG(salary) > 80000;

🎯 Interview question: WHERE vs HAVING?

Answer: WHERE acts before aggregation on rows; HAVING acts after aggregation on groups.

🎯 Interview question: Can HAVING be used without GROUP BY?

Answer: In many SQL dialects, yes, to filter a single aggregate result, but GROUP BY is the common use.

04 • NULLS & AGGREGATION

NULL handling

NULL represents unknown or missing data and affects aggregates and grouping.

Syntax / pattern

COALESCE(value, replacement)

Example

SELECT COALESCE(SUM(amount), 0) AS total
FROM orders;

🎯 Interview question: Why use COALESCE with SUM?

Answer: SUM can return NULL when no non-NULL values exist; COALESCE can replace it with 0.

🎯 Interview question: Does GROUP BY group NULLs?

Answer: Yes; NULL values can form a group.
